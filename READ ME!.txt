BEFORE YOU RUN THE PROJECT!: make sure you make an empty folder in you desktop or anywhere in your laptop/PC (mobile devices is not supported [yet])... after you make the folder, put all of the folder from the ZIP into the empty folder... after that you can run the project... 

project is still a python (.py) file, not a (.exe) file 

How To Run: 
	1.) install Python (in VScode) 
	2.) install PGzero: https://pygame-zero.readthedocs.io/en/stable/installation.html
 	3.) in the Terminal write: "python sans_adventure.py"

how to play: simple, because it's still work in progress project, soo not much will happen... kill the enemies in the map and win...
